Devices: laptop = Intel Core i5-8365U; Raspberry Pi 5 (8 GB); Jetson Orin Nano 8 GB
(Seeed reComputer J3011, JetPack 5, 15-W mode, GPU not used). LLM judge = qwen2.5:1.5b via Ollama.
Peak memory = peak resident memory of the whole process (Python + libraries + model), step 18.
(a) The Pi used a newer PyTorch build that already takes 879 MB before the model loads;
    the detector itself adds about 145 MB (laptop about 126 MB, Jetson about 151 MB).
Energy = (mean active power - mean idle power) x active seconds / entries checked, mean of
3 runs of 120 s each. Power source: laptop = CPU package power (HWiNFO64, step 19 + 19b);
Pi = PMIC supply rails (step 20); Jetson = INA3221 total module input VDD_IN (step 21).
Energy values are estimates from on-board sensors.
